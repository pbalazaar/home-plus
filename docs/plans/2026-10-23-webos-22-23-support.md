# webOS 22 and 23 compatibility implementation plan

**Goal:** Run the existing Home+ package's service on webOS 22 and 23's Node 12 runtimes, without changing newer-TV behavior or claiming untested device support.

**Architecture:** Keep one package and the existing native/QML front ends. Replace optional-call syntax and centralize forced file/tree removal behind a Node 12-compatible helper. Use native `fs.rm` on newer runtimes, and unlink/rmdir on Node 12; preserve symlink and error handling. Reuse the existing subprocess test harness for the older runtimes.

**Tech stack:** CommonJS, Node 12.21.0/12.22.2/16.19.1/20.12.2, Node 22 test runner, existing Docker toolchain, upstream webOSbrew compatibility verifier.

## 1. Establish the baseline

- [x] Run the existing service suite on Node 22.
- [x] Download checksum-verified Node runtimes for LG's webOS 22–26 versions.
- [x] Reproduce startup/parser failure on Node 12 before changes.

## 2. Backport the service

- [x] Add behavioral removal tests covering files, recursive directories, missing paths, nonrecursive refusal, symlinks and async completion, executed using `HOMEPLUS_SERVICE_NODE`.
- [x] Implement `service/remove.js`, replacing newer removal calls in `service/service.js` and `service/ambient.js` without globally patching `fs`.
- [x] Replace the two optional calls with ordinary guarded `getuid` calls.
- [x] Run syntax checks for all service modules and behavioral/API/overlay tests on Node 12.21 and 12.22.2, and regression checks on Node 16 and 20.

The first full Node 12 run also exposed two existing image-proxy failures: Node 12 can emit `aborted`, then `end`, before `close`. Handling `aborted` immediately prevents `pipe()` from finishing a truncated response and prevents a late close from destroying a reused downstream socket. The existing image tests reproduced both failures before the fix and pass afterwards.

## 3. Validate native compatibility and prevent regressions

- [x] Build the exact package and run its existing package checks.
- [x] Run the upstream compatibility verifier against internal releases 7.x/8.x (webOS 22/23), and investigate any imported-symbol blockers.
- [x] Extend the existing CI runtime matrix to Node 12.21.0, 12.22.2, 16.19.1, 16.20.2 and 20.12.2; keep the runner on Node 22.
- [x] Document the runtime target and evidence, keeping real-device status explicit. No TV install or publication is required for this local backport.
- [x] Review the diff and record validation results and remaining hardware tests (`docs/reviews/2026-10-23-webos-22-23-compatibility.md`). Independent review's Node 12 synchronous cleanup finding was reproduced, fixed and rechecked.
